## 💻 Ejecución en Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/JoseAFrancoG/jose-franco-portfolio.git
   cd jose-franco-portfolio
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en modo de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```

## ⚡ Despliegue en Vercel

Este proyecto está 100% optimizado para desplegarse en **Vercel** en un solo clic:

1. Ve a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add New..."** > **"Project"**.
3. Selecciona el repositorio **`jose-franco-portfolio`**.
4. Vercel detectará automáticamente que es un proyecto **Vite**:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Haz clic en **Deploy** y en pocos segundos estará online con certificado SSL gratuito y CDN global.
